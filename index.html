Project 01 — where it started

Discover Nepal

A travel exploration platform built to make browsing Nepal’s trekking regions and heritage sites feel effortless — from lakeside Pokhara to Everest Base Camp to the living heritage squares of Kathmandu.

Stack

  • HTML5
  • CSS3
  • Vanilla JavaScript

The problem

Most local travel pages I found were either dense text blocks or tourism-board PDFs. I wanted something that let a visitor scan destinations by region and elevation, in a layout that felt closer to a modern product than a brochure.

What I learned

How to structure a multi-page site with shared navigation, how to build an account modal with tab-switching login/signup states, and — mostly — how much CSS it actually takes to make something look simple.

Challenges

Keeping the layout consistent across four separate HTML pages without a framework meant a lot of manual discipline with shared classes and spacing tokens. That friction is part of why learning React is next.
